## FILLED EXAMPLE: E-Commerce Product Page

### Affordances: 7/10
- ✓ "Add to Cart" button clearly looks pressable (color, shadow, size)
- ✓ Product images are clearly clickable
- ✓ Star rating is visually distinct
- ✗ Quantity selector unclear (not obvious it's editable)
- ✗ "Save for later" icon not clear (heart icon, but small)

**Issues:** Small heart icon, quantity field needs better affordance

### Feedback: 6/10
- ✓ "Added to cart" notification appears
- ✗ No loading state while adding to cart
- ✗ No indication when product is out of stock changes
- ✗ Slow page load with no progress indicator

**Issues:** Missing loading feedback, no real-time stock status updates

### Constraints: 8/10
- ✓ Can't enter negative quantity
- ✓ Max quantity enforced
- ✓ Checkout disabled if required fields empty
- ✗ Can add out-of-stock items to cart (should prevent)

**Issues:** Allow adding unavailable items

### Clarity: 7/10
- ✓ Price very prominent
- ✓ "Add to Cart" is obvious primary action
- ✗ Shipping cost hidden until checkout
- ✗ Return policy requires clicking link

**Issues:** Shipping cost not upfront, return policy obscured

**OVERALL: 7/10** - Solid foundation, needs clarity improvements on costs and stock status
