# E-Commerce Design

**Primary Goals:**
- Increase conversion rate
- Build customer trust
- Reduce cart abandonment
- Encourage repeat purchases

**Core Principles (Adapted):**
1. **Build trust** (Don Norman - affordances signal reliability)
   - Security badges
   - Return policy clarity
   - Customer reviews
   - Contact information visible
   - Real company details

2. **Reduce friction** (Steve Krug - simplicity)
   - Guest checkout option
   - Few form fields
   - Clear shipping cost upfront
   - Save payment methods
   - One-click checkout

3. **Enable discovery** (Tidwell - patterns)
   - Browse and search both available
   - Filtering and sorting
   - Related products
   - Product recommendations
   - Clear categories

4. **Clear pricing** (Nodder - transparency)
   - Price prominent
   - No surprise costs
   - Compare options visible
   - Discounts clear
   - Savings obvious

5. **Social proof** (Nodder - persuasion)
   - Customer reviews
   - Star ratings
   - Purchase counts ("X people bought")
   - User testimonials
   - Trust badges

**Critical Metrics:**
- Conversion rate (primary)
- Cart abandonment rate
- Average order value
- Customer lifetime value
- Return rate

**Common E-Commerce Patterns:**
- Product cards (image + price + rating)
- Search + filter + sort
- Wish lists / saved items
- Guest checkout
- Multiple payment methods
- Easy returns / refunds

**Critical Mistakes to Avoid:**
- ❌ Hiding shipping cost until checkout
- ❌ Forcing account creation
- ❌ Unclear return policy
- ❌ Slow product pages
- ❌ No reviews/social proof
- ❌ Confusing pricing

**Testing Approach:**
- User testing on product discovery
- A/B test checkout flow
- Analyze cart abandonment
- Test trust signals
- Interview recent customers
